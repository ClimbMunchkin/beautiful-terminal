# Установка красивого терминала под ключ (zsh, Oh My Zsh и темы powerlevel10k)

- Установка шрифта FiraCode для поддержки пиктограмм в терминале
- Установка zsh, Oh My Zsh и темы powerlevel10k
- Устанавливаем тему p10k и добавляем плагины zsh-syntax-highlighting, zsh-autosuggestions в .zshrc 


Скопируйте установочный скрипт в буфер и запустите его  в командной строке

``` 
sudo apt update && sudo apt install -y git && cd ~ &&
git clone https://github.com/ClimbMunchkin/beautiful-terminal.git beautiful-terminal &&
bash ~/beautiful-terminal/install-zsh-omz-p10k.sh
```
