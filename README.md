# Установка красивого терминала под ключ (zsh, Oh My Zsh и темы powerlevel10k)

## Что устанавливается

- **FiraCode Nerd Font** — шрифт с поддержкой пиктограмм (иконок) для терминала
- **zsh** — современная оболочка командной строки
- **Oh My Zsh** — фреймворк для управления конфигурацией zsh
- **powerlevel10k** — быстрая и настраиваемая тема для zsh
- **Плагины zsh**:
  - `zsh-syntax-highlighting` — подсветка синтаксиса
  - `zsh-autosuggestions` — автодополнение по истории команд
- Готовый конфиг `.p10k.zsh` (опционально)

## Требования

- Ubuntu/Debian (или совместимый дистрибутив с `apt`)
- Права `sudo` (для установки zsh и смены оболочки по умолчанию)
- Установленный `git` (устанавливается в команде ниже)

Скрипт сам проверит наличие необходимых утилит: `curl`, `unzip`, `fc-cache`, `git`.

## Быстрая установка

Скопируйте команду и выполните её в терминале:

``` 
sudo apt update && sudo apt install -y git && cd ~ &&
git clone https://github.com/ClimbMunchkin/beautiful-terminal.git beautiful-terminal &&
bash ~/beautiful-terminal/install-zsh-omz-p10k.sh
```


После завершения установки перезагрузите систему (или выйдите и войдите снова) — настройки вступят в силу.

## Что делает скрипт

1. Шрифт FiraCode Nerd Font

	- Скачивает архив с GitHub (версия v3.5.1)

	- Распаковывает и копирует .ttf/.otf в ~/.local/share/fonts

	- Обновляет кэш шрифтов (fc-cache)

	- Настраивает моноширинный шрифт терминала в GNOME (FiraCode Nerd Font 11)

2. zsh

	- Устанавливает zsh через apt, если ещё не установлен

	- Меняет оболочку по умолчанию на /bin/zsh

3. Oh My Zsh

	- Устанавливает без запуска zsh и без перезаписи существующего ~/.zshrc

4. powerlevel10k

	- Клонирует тему в ~/.oh-my-zsh/custom/themes/powerlevel10k

	- Обновляет репозиторий, если тема уже установлена

5. Конфигурация ~/.zshrc

	- Устанавливает тему powerlevel10k/powerlevel10k

	- Подключает плагины git, zsh-syntax-highlighting, zsh-autosuggestions

	- Добавляет загрузку ~/.p10k.zsh (если файл существует)

6. Готовый конфиг .p10k.zsh

	- Если в репозитории есть beautiful-terminal/.p10k.zsh, скрипт предложит его использовать

	- Если конфиг уже существует — мастер настройки не запускается

---
## После установки

Настройки вступят в силу после перезагрузки или повторного входа

Для тонкой настройки внешнего вида темы выполните:
```
p10k configure
```

## Примечания

Скрипт использует set -euo pipefail — при любой ошибке выполнение прерывается
Временные файлы автоматически удаляются при выходе
Смена оболочки через chsh вступит в силу только после повторного входа в систему
Настройка шрифта через gsettings работает в окружении GNOME; в других DE её нужно выполнить вручную
